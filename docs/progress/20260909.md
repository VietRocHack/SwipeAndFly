# 2026-09-09

## Migrate off OpenAI, deploy to vietrochack-lab

- Swapped the default LLM provider from OpenAI to Gemini (via Gemini's
  OpenAI-compatible endpoint - no new SDK needed), keeping OpenAI/Groq as
  non-default options. See ADR 0003.
- Replaced DynamoDB (needed AWS credentials Cloud Run can't mount) with a
  dedicated Firestore database. See ADR 0002.
- Deployed to Cloud Run + Firebase Hosting under `vietrochack-lab`,
  following the migration-guide playbook adapted for this app's
  single-container topology (Flask serves frontend + API from one
  origin, so Hosting rewrites everything to Cloud Run rather than just
  `/api/**`). See ADR 0001.
- Set up push-to-main CI/CD via GitHub Actions + Workload Identity
  Federation (no stored service-account keys), scoped to this repo in
  the shared `github` WIF pool.
- Requested the `swipeandfly.vietrochack.com` custom domain; DNS records
  handed off for someone with Namecheap access to add (see
  `docs/runbook.md`).
- Along the way, fixed three pre-existing bugs the deploy surfaced:
  - `Dockerfile` installed `libgl1-mesa-glx`, which no longer exists on
    the Debian release `python:3.11-slim` now resolves to (opencv needs
    `libgl1` + `libglib2.0-0` instead).
  - The container hardcoded gunicorn to port 5000; Cloud Run requires
    listening on `$PORT` (8080).
  - `itinerary_routes.py` built an OpenAI client at *import time* using
    `GROQ_API_KEY` (dead code, never actually called) - crashed the
    entire app on startup once that key wasn't provisioned.
  - `HTTP_INTERNAL_SERVER_ERROR = 500,` (stray trailing comma) was a
    1-tuple, not an int - any route returning it as a status code crashed
    instead of actually responding 500.
- Verified: homepage, Maps Places autocomplete, and the video-analysis
  API route all work end-to-end against the live Cloud Run + Hosting
  deploy (`vietrochack-swipeandfly.web.app`), checked via browser
  automation and curl.
- Backported the lessons from this migration into the
  [migration-guide](https://github.com/VietRocHack/migration-guide) repo.
